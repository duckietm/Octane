# AIR own-avatar menu assets

These bitmaps are exported from the local WIN63 `HabboAir.swf` reference and are used by `own_avatar_menu_xml`.

- `bubble.png` and `bubble-pointer-down.png`: the tinted Ubuntu bubble 9-slice and its 13×9 down pointer (`habbo_skin_bubble_xml`, `habbo_skin_bubble_pointer_down_xml`).
- `button-thick-*.png`: the four style-3 `button_shiny_thick` states used by 109×35 action buttons, tinted with the runtime default/hover colors.
- `button-grid-*.png`: the four style-0 `button` states used by 39×29 sign-grid buttons, tinted with the runtime default/hover colors.
- `arrow-*.png`: icon-set styles 4–7, including the AIR hover tint for the minimize control (`habbo_skin_icon_set_xml`).
- `vip.png`: icon-set style 14, rendered at 15×15.
- `switch.png`: `illumina_light_switch_png`, the two 38×21 states of the style-100 checkbox (`illumina_light_skin_switch_xml`: on at y=0, off at y=22), used by the bot chat window.
- `sign-*.png`: the embedded `sign_icon_heart`, `sign_icon_skull`, and `sign_icon_13`–`sign_icon_17` classes used by the 3×6 sign grid.

The authoritative layout is `reference/habbo-air/decompiled/binaryData/962_own_avatar_menu_xml$467fd7c39d55dbe5b5759d09c9788a0a416847910.bin` in the Polaris workspace.
