# AIR settings assets

These bitmaps come from the local WIN63 `HabboAir.swf` dump in
`reference/habbo-air/decompiled/images`.

- `slider-base.png`: `toolbar_memenu_settings_slider_base`, 139×20
- `slider-button.png`: `toolbar_memenu_settings_slider_button`, 12×15
- `sounds-*-white.png` / `sounds-*-color.png`: AIR speaker states, 29×22
- `border-ubuntu-6-79756e.png`: the `habbo_skin_ubuntu_png` border-6
  nine-slice assembled from its XML regions, tinted with the settings window
  color `#79756e`, and nearest-neighbour scaled to 2× for CSS border slicing

Authoritative layouts are `me_menu_settings_menu_xml`,
`me_menu_sound_settings_xml`, `toolbar_chat_settings_xml`, and
`me_menu_other_settings_xml` in the same dump.
