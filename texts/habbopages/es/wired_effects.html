Efectos Wired

¿Cómo funcionan los efectos Wired?

WIRED Efecto: Se activa el furni

Con este efecto, el furni elegido reacciona como si se hubiera hecho doble clic en él.

WIRED Efecto: Teletransportar a un furni

Este efecto teletransporta a un furni al Habbo que realiza la acción. Si seleccionas más de 1 furni, la persona irá al azar a uno de esos furnis.

WIRED Efecto: Teletransportar Bot a un furni

Este efecto hace que el Bot se teletransporte a uno de los furnis seleccionados

WIRED Efecto: El Bot se cambia de ropa

El efecto hace que el Bot se ponga otra ropa.

WIRED Efecto: El Bot se desplaza a un furni

Este efecto hace que el Bot se desplace al furni seleccionado

WIRED Efecto: El Bot habla o grita a todos los usuarios

Este efecto hace que el Bot hable o grite a todos los usuarios

WIRED Efecto: El Bot habla o susurra al usuario

Este efecto hace que el Bot hable o susurre al usuario causante

WIRED Efecto: El Bot sigue al usuario

Este efecto hace que el Bot siga a los usuarios seleccionados.

WIRED Efecto: El Bot da un objeto de mano

Este efecto hace que el Bot seleccionado dé el objeto de mano seleccionado.

WIRED EFECTO: Expulsar usuario

Este efecto expulsa a un usuario en función de los causantes

WIRED Efecto: Mostrar mensaje

Este efecto muestra un mensaje secreto a la persona que realiza la acción.

WIRED Efecto: El furni se mueve y/o gira

Este efecto mueve y gira los furnis seleccionados

WIRED Efecto: Mover furni a posición y estado.

Este efecto mueve los furnis seleccionados a la posición y el estado establecidos. Así puedes mover varios furnis o hacer que una puerta se abra siempre como efecto.

WIRED EFECTO: Ejecutar pilas de Wired

Con este Wired puedes seleccionar 5 pilas de Wired para ejecutarlas con un único causante, sin importar las condiciones o los causantes existentes.

WIRED Efecto: Reiniciar temporizador

Con este efecto reinicias los causantes que tienen un temporizador.

WIRED Efecto: Dar puntos

Da una cantidad de puntos al equipo que activa el efecto. También puedes elegir cuántas veces como máximo se reparten esos puntos durante el juego.

WIRED Extra: Efecto aleatorio

Cuando la pila se active, se iniciará 1 efecto aleatorio de esta pila.

WIRED Extra: Efecto no utilizado

Se iniciará 1 de los efectos de esta pila que todavía no se hayan utilizado.

WIRED EFECTO: Perseguir

Este efecto mueve el furni hacia el jugador más cercano en la misma fila o columna. Si hay un usuario junto a este furni, se activa el Wired Causante: colisión usuario-furni.

WIRED EFECTO: Huir

Al activarse, el furni se desliza una baldosa alejándose de la persona más cercana.

WIRED EFECTO: Dar puntos

Da puntos al equipo establecido

WIRED EFECTO: Unirse al equipo

El Habbo causante se une al equipo establecido

WIRED EFECTO: Abandonar equipo

El Habbo causante abandona el equipo establecido

WIRED Efecto: Cambiar la dirección del furni

Este efecto cambia la dirección del furni. Si el movimiento queda bloqueado, el furni cambiará de dirección según tu configuración. Si hay un jugador junto al furni, se activa el Wired Causante: colisión usuario-furni.
