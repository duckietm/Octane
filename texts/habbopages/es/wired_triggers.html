Causantes Wired

¿Cómo funcionan los causantes Wired?

WIRED Causante: Una persona pisa un furni

El causante se activa cuando una persona se pone de pie o se sienta sobre un furni.

WIRED Causante: Una persona se baja de un furni

El causante se activa cuando una persona se baja de un furni.

WIRED Causante: El Bot alcanza a un usuario

Los efectos se activan cuando el Bot seleccionado alcanza a un usuario

WIRED Causante: El Bot alcanza un furni

Los efectos se activan cuando el Bot seleccionado alcanza uno de los furnis seleccionados

WIRED Causante: Una persona dice la palabra correcta

El causante se activa cuando una persona dice una palabra o una frase especial.

WIRED Causante: Una persona hace doble clic en un furni

El causante se activa cuando el estado de un furni ha cambiado al hacer doble clic en él.

WIRED Causante: Una persona entra en la sala

El causante se activa cuando un Habbo entra en una sala.

WIRED Causante: Repetir efecto

El efecto se activa cada x segundos.

WIRED Causante: En el momento x

El causante se activa en un momento fijo después de reiniciar el temporizador.

WIRED CAUSANTE: Puntuación alcanzada

Se activa cuando se alcanza la puntuación indicada

WIRED Causante: El juego termina

El causante se activa cuando termina en la sala un juego con un furni temporizador.

WIRED Causante: El juego empieza

El causante se activa cuando empieza un juego con un furni temporizador.

WIRED CAUSANTE: Colisión

Se activa cuando un furni movido (con el Wired Perseguir o Huir) choca con una persona; el usuario causante es la persona que choca.

WIRED CAUSANTE: Repetir largo

¡Juegos más largos! El causante se activa cada vez que se agota el tiempo indicado. Como el Causante Repetir, ¡pero más largo!
