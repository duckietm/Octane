Variables permanentes de usuario

Con esta herramienta puedes gestionar las variables permanentes de un usuario, una mascota o un bot. Las variables que aparecen en este resumen se guardan en la base de datos de Habbo, lo que te permite ver y gestionar las variables de usuarios desconectados y de usuarios que no están en la sala.

¿Están actualizadas?

Los valores de esta ventana están siempre actualizados, salvo por un retraso de 20 segundos si el usuario está en ese momento en otra sala en la que se está usando la variable

¿Puedo cambiar el valor de una variable?

Puedes cambiar el valor de una variable para usuarios desconectados y para usuarios que no estén usando las variables. Sin embargo, si el usuario está en ese momento dentro de una sala que usa la variable, la sala tiene una copia de esa variable y podría sobrescribirla en la base de datos de Habbo cuando el usuario salga de la sala, deshaciendo los cambios hechos con esta herramienta. Está diseñado así a propósito.

En esos casos se recomienda usar la herramienta de Inspección. Si quieres gestionar las variables de muchos usuarios a la vez y no sabes cuáles de ellos están dentro de tu(s) sala(s), se recomienda cerrar primero tus salas mientras haces el mantenimiento.
