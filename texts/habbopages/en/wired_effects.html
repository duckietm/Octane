Wired Effects

How do Wired effects work?

WIRED Effect: Furni is activated

With this Effect, a chosen furni reacts as if it had been double-clicked.

WIRED Effect: Teleport to furni

This effect teleports the Habbo performing the action to a furni. If you select more than 1 furni, the user is placed on one of those furni at random.

WIRED Effect: Teleport Bot to furni

This effect teleports the Bot to one of the selected furni

WIRED Effect: Bot changes clothes

The effect makes the Bot wear different clothes.

WIRED Effect: Bot moves to furni

This effect makes the Bot move to the selected furni

WIRED Effect: Bot talks or shouts to all users

This effect makes the Bot talk or shout to all users

WIRED Effect: Bot talks or whispers to the user

This effect makes the Bot talk or whisper to the triggering user

WIRED Effect: Bot follows user

This effect makes the Bot follow the selected users.

WIRED Effect: Bot gives hand item

This effect makes the selected Bot give the selected hand item.

WIRED EFFECT: Kick user

This Effect kicks a user based on Triggers

WIRED Effect: Show message

This effect shows a secret message to the user performing the action.

WIRED Effect: Furni is moved and/or rotated

This effect moves and rotates the selected furni

WIRED Effect: Furni moved to location & state.

This effect moves the selected furni to the set position and state. This is how you move several furni or make a door always open as an Effect.

WIRED EFFECT: Execute Wired stacks

With this Wired you can select 5 Wired stacks to execute with a single Trigger, regardless of the existing Conditions or Triggers.

WIRED Effect: Timer reset

With this effect you reset triggers that have a timer attached.

WIRED Effect: Give points

This gives a number of points to the team that activates the effect. You can also choose the maximum number of times those points are handed out during the game.

WIRED Add-on: Random Effect

1 random Effect from this stack will start when the stack is activated.

WIRED Add-on: Unused Effect

1 of the effects from this stack that has not been used yet will start.

WIRED EFFECT: Chase

This effect moves the furni towards the nearest player in the same row or column. If a user is standing next to this furni, the Wired Trigger: user item collision is activated.

WIRED EFFECT: Flee

When activated, the furni slides one tile away from the nearest user.

WIRED EFFECT: Give Points

Gives points to the specified team

WIRED EFFECT: Join Team

The triggering Habbo joins the specified team

WIRED EFFECT: Leave Team

The triggering Habbo leaves the specified team

WIRED Effect: Change the direction of furni

This effect changes the direction of the furni. If the movement is blocked, the furni will change direction based on your settings. If a player is standing next to the furni, the Wired Trigger: user item collision is activated.
