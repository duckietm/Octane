Permanent User Variables

In this tool, you can manage the permanent variables of a user, pet or bot. Variables shown in this overview are stored in the Habbo Database, allowing you to see and manage variables of offline users and users who are not in the room.

Are they up-to-date?

The values in this window are always up-to-date, except for a 20-second delay if the user is currently in another room where the variable is being used

Can I change the value of a variable?

You may change the value of a variable for offline users and users who are not using the variables. However, if the user is currently inside a room that uses the variable, the room has a copy of that variable and might overwrite it in the Habbo Database when the user leaves the room, undoing changes made with this tool. This is intended design.

In these cases it is recommended to use the Inspection tool instead. If you want to manage variables of many users at the same time and you do not know which of the users are inside your room(s), it is recommended to close your rooms first while you do maintenance.
