Wired Conditions

How do Wired conditions work?

WIRED CONDITION: Group Member

The condition is valid when this is a group room and the avatar is a member of this group.

WIRED Condition: Furni has another furni on it

Effects can only be activated if there is another piece of furni on the chosen furni.

WIRED Condition: User has hand item

Triggering is allowed if the user is holding the selected hand item

WIRED Negative Condition: Has NO furni on it

Triggering is allowed if there is NO furni on the chosen furni.

WIRED Negative Condition: NO avatar is standing on the furni

Triggering is allowed if there are NO avatars standing on one of the chosen furni.

WIRED Negative Condition: NOT a group member

The condition is valid when this is a group room and the avatar is NOT a member of this group.

WIRED Negative Condition: NOT a team member

The condition is valid when the avatar is NOT a member of the specified team.

WIRED Negative Condition: Furni state does NOT match..

Triggering is allowed when the state of the picked furni does NOT match.

WIRED Condition: Furni Type does NOT match.

Triggering is allowed when the furni described in the trigger is NOT one of the chosen furni or is NOT of the same type.

WIRED Negative Condition: Triggerer is NOT on FURNI

Triggering is allowed if the triggerer is NOT standing on one of the chosen furni.

WIRED Negative Condition: User count in the room does NOT match

Triggering is allowed if the number of users in the room is NOT within the specified limits.

WIRED CONDITION: Team Member

Condition is met if the Habbo is a member of the specified team

WIRED Condition: Any Habbo must be standing on furni

The action only starts if there is a Habbo standing on all selected furni.

WIRED Condition: Furni must be in the right state and position

The action only starts if the state and position of the chosen furni are the same.

WIRED CONDITION: Same furni type

Triggering is allowed when the furni described by the trigger is one of the chosen furni or is of the same type.

WIRED Condition: Less than x seconds have passed since timer reset.

The action only starts if less than x seconds have passed since the timer reset.

WIRED Condition: More than x seconds have passed since timer reset.

The action only starts if more than x seconds have passed since the timer reset.

WIRED Condition: Triggering Habbo must be standing on furni

The action only starts if the Habbo performing the action is standing on one of the selected furni.

WIRED Condition: number of users in room

Triggering is allowed when the number of users in the room is within the limits.
