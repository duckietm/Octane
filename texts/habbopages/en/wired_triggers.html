Wired Triggers

How do Wired triggers work?

WIRED Trigger: User walks on furni

The trigger fires when a user stands or sits on a furni.

WIRED Trigger: User walks off furni

The trigger fires when a user steps off a furni.

WIRED Trigger: Bot reaches user

Effects are activated when the selected Bot reaches a user

WIRED Trigger: Bot reaches furni

Effects are activated when the selected Bot reaches one of the selected furni

WIRED Trigger: User says the right word

The trigger fires when a user says a special word or phrase.

WIRED Trigger: User double-clicks furni

The trigger fires when the state of a furni has been changed by double-clicking it.

WIRED Trigger: User enters room

The trigger fires when a Habbo enters a room.

WIRED Trigger: Repeat effect

The effect is activated every x seconds.

WIRED Trigger: At moment x

The trigger fires at a fixed moment after the timer has been reset.

WIRED TRIGGER: Score Achieved

Is activated when the specified score has been achieved

WIRED Trigger: Game ends

The trigger fires when a game with a Timer furni has ended in the room.

WIRED Trigger: Game starts

The trigger fires when a game starts with a Timer furni.

WIRED TRIGGER: Collision

Is activated when a furni moved (with the Wired Chase or Flee) collides with a user; the triggering user is the user who collides.

WIRED TRIGGER: Repeat Long

Longer games! The trigger fires every time the specified time is up. Like the Repeat Trigger, but longer!
