Variables permanentes d'utilisateur

Cet outil te permet de gérer les variables permanentes d'un utilisateur, d'un animal ou d'un bot. Les variables affichées ici sont stockées dans la base de données Habbo, ce qui te permet de voir et de gérer les variables des utilisateurs hors ligne et de ceux qui ne sont pas dans l'appart.

Sont-elles à jour ?

Les valeurs de cette fenêtre sont toujours à jour, à un délai de 20 secondes près si l'utilisateur se trouve actuellement dans un autre appart où la variable est utilisée

Puis-je modifier la valeur d'une variable ?

Tu peux modifier la valeur d'une variable pour les utilisateurs hors ligne et pour ceux qui n'utilisent pas les variables. En revanche, si l'utilisateur se trouve dans un appart qui utilise la variable, cet appart en détient une copie et peut l'écraser dans la base de données Habbo quand l'utilisateur quitte l'appart, annulant ainsi les modifications faites avec cet outil. Ce fonctionnement est voulu.

Dans ce cas, il vaut mieux utiliser l'outil Inspection. Si tu veux gérer les variables de nombreux utilisateurs en même temps sans savoir lesquels se trouvent dans ton ou tes apparts, il est conseillé de fermer d'abord tes apparts le temps de la maintenance.
