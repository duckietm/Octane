Déclencheurs Wired

Comment fonctionnent les déclencheurs Wired ?

WIRED Déclencheur : Une personne monte sur un mobi

Le déclencheur s'active quand une personne se place ou s'assoit sur un mobi.

WIRED Déclencheur : Une personne descend d'un mobi

Le déclencheur s'active quand une personne descend d'un mobi.

WIRED Déclencheur : Le Bot atteint un utilisateur

Les effets sont activés lorsque le Bot sélectionné atteint un utilisateur

WIRED Déclencheur : Le Bot atteint un mobi

Les effets sont activés lorsque le Bot sélectionné atteint l'un des mobis sélectionnés

WIRED Déclencheur : Une personne dit le bon mot

Le déclencheur s'active quand une personne dit un mot spécial ou une phrase spéciale.

WIRED Déclencheur : Une personne double-clique sur un mobi

Le déclencheur s'active quand l'état d'un mobi a été modifié par un double-clic.

WIRED Déclencheur : Une personne entre dans l'appart

Le déclencheur s'active quand un Habbo entre dans un appart.

WIRED Déclencheur : Répéter l'effet

L'effet est activé toutes les x secondes.

WIRED Déclencheur : Au moment x

Le déclencheur s'active à un moment précis après la réinitialisation du minuteur.

WIRED DÉCLENCHEUR : Score atteint

S'active quand le score indiqué est atteint

WIRED Déclencheur : Fin du jeu

Le déclencheur s'active quand un jeu avec un mobi Minuteur se termine dans l'appart.

WIRED Déclencheur : Début du jeu

Le déclencheur s'active quand un jeu commence avec un mobi Minuteur.

WIRED DÉCLENCHEUR : Collision

S'active quand un mobi déplacé (avec les Wired Poursuite ou Fuite) percute une personne ; l'utilisateur déclencheur est la personne percutée.

WIRED DÉCLENCHEUR : Périodique long

Des jeux plus longs ! Le déclencheur s'active chaque fois que le temps indiqué est écoulé. Comme le Déclencheur Périodique, mais en plus long !
