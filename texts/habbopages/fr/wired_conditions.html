Conditions Wired

Comment fonctionnent les conditions Wired ?

WIRED CONDITION : Membre du groupe

La condition est valable lorsqu'il s'agit d'un appart de groupe et que l'avatar est membre de ce groupe.

WIRED Condition : Un autre mobi se trouve sur le mobi

Les effets ne peuvent être activés que si un autre mobi se trouve sur le mobi choisi.

WIRED Condition : L'utilisateur a un objet en main

Le déclenchement est autorisé si l'utilisateur tient l'objet en main sélectionné

WIRED Condition négative : AUCUN mobi dessus

Le déclenchement est autorisé s'il n'y a AUCUN mobi sur le mobi choisi.

WIRED Condition négative : AUCUN avatar sur le mobi

Le déclenchement est autorisé s'il n'y a AUCUN avatar sur l'un des mobis choisis.

WIRED Condition négative : PAS membre du groupe

La condition est valable s'il s'agit d'un appart de groupe et que l'avatar n'est PAS membre de ce groupe.

WIRED Condition négative : PAS membre de l'équipe

La condition est valable lorsque l'avatar n'est PAS membre de l'équipe définie.

WIRED Condition négative : L'état des mobis ne correspond PAS..

Le déclenchement est autorisé lorsque l'état des mobis sélectionnés ne correspond PAS.

WIRED Condition : Le type de mobi ne correspond PAS.

Le déclenchement est autorisé lorsque le mobi désigné par le déclencheur n'est PAS l'un des mobis choisis ou n'est PAS du même type.

WIRED Condition négative : Le déclencheur n'est PAS sur le MOBI

Le déclenchement est autorisé si le déclencheur ne se trouve PAS sur l'un des mobis choisis.

WIRED Condition négative : Le nombre d'utilisateurs dans l'appart ne correspond PAS

Le déclenchement est autorisé si le nombre d'utilisateurs dans l'appart n'est PAS compris dans les limites indiquées.

WIRED CONDITION : Membre de l'équipe

La condition est remplie si le Habbo est membre de l'équipe définie

WIRED Condition : Un Habbo quelconque doit se trouver sur le mobi

L'action ne démarre que s'il y a un Habbo sur tous les mobis sélectionnés.

WIRED Condition : Les mobis doivent être dans le bon état et à la bonne position

L'action ne démarre que si l'état et la position des mobis choisis sont identiques.

WIRED CONDITION : Même type de mobi

Le déclenchement est autorisé lorsque le mobi désigné par le déclencheur est l'un des mobis choisis ou est du même type.

WIRED Condition : Moins de x secondes se sont écoulées depuis la réinitialisation du minuteur.

L'action ne démarre que si moins de x secondes se sont écoulées depuis la réinitialisation du minuteur.

WIRED Condition : Plus de x secondes se sont écoulées depuis la réinitialisation du minuteur.

L'action ne démarre que si plus de x secondes se sont écoulées depuis la réinitialisation du minuteur.

WIRED Condition : Le Habbo déclencheur doit se trouver sur le mobi

L'action ne démarre que si le Habbo qui effectue l'action se trouve sur l'un des mobis sélectionnés.

WIRED Condition : nombre d'utilisateurs dans l'appart

Le déclenchement est autorisé lorsque le nombre d'utilisateurs dans l'appart est compris entre les limites.
