Permanente User-Variablen

In diesem Tool kannst du die permanenten Variablen eines Users, Haustiers oder Bots verwalten. Die Variablen in dieser Übersicht sind in der Habbo-Datenbank gespeichert. So kannst du auch die Variablen von Usern sehen und verwalten, die offline oder nicht im Raum sind.

Sind sie aktuell?

Die Werte in diesem Fenster sind immer aktuell, abgesehen von einer Verzögerung von 20 Sekunden, wenn der User sich gerade in einem anderen Raum befindet, in dem die Variable verwendet wird

Kann ich den Wert einer Variable ändern?

Du kannst den Wert einer Variable für User ändern, die offline sind oder die Variablen gerade nicht verwenden. Befindet sich der User aber gerade in einem Raum, der die Variable verwendet, hat der Raum eine Kopie dieser Variable und überschreibt sie möglicherweise in der Habbo-Datenbank, wenn der User den Raum verlässt. Damit werden Änderungen aus diesem Tool rückgängig gemacht. Das ist so gewollt.

In diesen Fällen empfehlen wir, stattdessen das Inspektions-Tool zu verwenden. Wenn du die Variablen vieler User gleichzeitig verwalten möchtest und nicht weißt, welche der User sich in deinen Räumen befinden, empfehlen wir, deine Räume für die Dauer der Wartung zuerst zu schließen.
