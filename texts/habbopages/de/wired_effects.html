Wired Effekte

Wie funktionieren Wired Effekte?

WIRED Effekt: Möbel wird aktiviert

Mit diesem Effekt reagiert ein gewähltes Möbel so, als wäre es doppelt angeklickt worden.

WIRED Effekt: Teleport zum Möbel

Dieser Effekt teleportiert den auslösenden Habbo zu einem Möbel. Wenn du mehr als 1 Möbel auswählst, wird die Person zufällig auf eines dieser Möbel gesetzt.

WIRED Effekt: Bot zum Möbel teleportieren

Dieser Effekt sorgt dafür, dass der Bot zu einem der ausgewählten Möbel teleportiert wird

WIRED Effekt: Bot zieht sich um

Der Effekt sorgt dafür, dass der Bot andere Kleidung bekommt.

WIRED Effekt: Bot bewegt sich zum Möbel

Dieser Effekt sorgt dafür, dass sich der Bot zum ausgewählten Möbel bewegt

WIRED Effekt: Bot spricht oder ruft zu allen Usern

Dieser Effekt sorgt dafür, dass der Bot zu allen Usern spricht oder ruft

WIRED Effekt: Bot spricht oder flüstert mit dem User

Dieser Effekt sorgt dafür, dass der Bot mit dem auslösenden User spricht oder flüstert

WIRED Effekt: Bot folgt User

Dieser Effekt sorgt dafür, dass der Bot den ausgewählten Usern folgt.

WIRED Effekt: Bot gibt Handitem

Dieser Effekt sorgt dafür, dass der ausgewählte Bot das ausgewählte Handitem gibt.

WIRED EFFEKT: User rauswerfen

Dieser Effekt wirft einen User anhand von Auslösern raus

WIRED Effekt: Nachricht anzeigen

Dieser Effekt zeigt der auslösenden Person eine geheime Nachricht.

WIRED Effekt: Möbel wird bewegt und/oder gedreht

Dieser Effekt bewegt und dreht die ausgewählten Möbel

WIRED Effekt: Möbel an Position & in Zustand versetzen.

Dieser Effekt versetzt die ausgewählten Möbel an die eingestellte Position und in den eingestellten Zustand. So bewegst du mehrere Möbel oder stellst ein, dass eine Tür als Effekt immer aufgehen soll.

WIRED EFFEKT: Wired Stapel ausführen

Mit diesem Wired kannst du 5 Wired Stapel auswählen, die mit einem einzigen Auslöser ausgeführt werden, unabhängig von den vorhandenen Bedingungen oder Auslösern.

WIRED Effekt: Timer-Reset

Mit diesem Effekt setzt du Auslöser zurück, an denen ein Timer hängt.

WIRED Effekt: Punkte geben

Gibt dem Team, das den Effekt auslöst, eine Anzahl von Punkten. Du kannst auch festlegen, wie oft diese Punkte im Spiel höchstens vergeben werden.

WIRED Erweiterung: Zufälliger Effekt

Wenn der Stapel aktiviert wird, startet 1 zufälliger Effekt aus diesem Stapel.

WIRED Erweiterung: Unbenutzter Effekt

Es startet 1 der noch nicht zuvor benutzten Effekte aus diesem Stapel.

WIRED EFFEKT: Verfolgen

Dieser Effekt bewegt das Möbel zum nächstgelegenen Spieler in derselben Reihe oder Spalte. Wenn ein User neben diesem Möbel steht, wird der Wired Auslöser: Kollision zwischen User und Möbel aktiviert.

WIRED EFFEKT: Fliehen

Nach dem Aktivieren rückt das Möbel ein Feld von der nächstgelegenen Person weg.

WIRED EFFEKT: Punkte Geben

Gibt dem eingestellten Team Punkte

WIRED EFFEKT: Team Beitreten

Der auslösende Habbo tritt dem eingestellten Team bei

WIRED EFFEKT: Team Verlassen

Der auslösende Habbo verlässt das eingestellte Team

WIRED Effekt: Richtung des Möbels ändern

Dieser Effekt ändert die Richtung des Möbels. Wenn die Bewegung blockiert wird, ändert das Möbel seine Richtung anhand deiner Einstellungen. Wenn ein Spieler neben dem Möbel steht, wird der Wired Auslöser: Kollision zwischen User und Möbel aktiviert.
