Wired Auslöser

Wie funktionieren Wired Auslöser?

WIRED Auslöser: Person betritt Möbel

Der Auslöser wird aktiviert, wenn sich eine Person auf ein Möbel stellt oder setzt.

WIRED Auslöser: Person verlässt Möbel

Der Auslöser wird aktiviert, wenn eine Person von einem Möbel heruntergeht.

WIRED Auslöser: Bot erreicht User

Effekte werden aktiviert, wenn der ausgewählte Bot einen User erreicht

WIRED Auslöser: Bot erreicht Möbel

Effekte werden aktiviert, wenn der ausgewählte Bot eines der ausgewählten Möbel erreicht

WIRED Auslöser: Person sagt das richtige Wort

Der Auslöser wird aktiviert, wenn eine Person ein bestimmtes Wort oder einen bestimmten Satz sagt.

WIRED Auslöser: Person doppelklickt auf Möbel

Der Auslöser wird aktiviert, wenn der Zustand eines Möbels durch einen Doppelklick verändert wurde.

WIRED Auslöser: Person betritt den Raum

Der Auslöser wird aktiviert, wenn ein Habbo einen Raum betritt.

WIRED Auslöser: Effekt wiederholen

Der Effekt wird alle x Sekunden aktiviert.

WIRED Auslöser: Zum Zeitpunkt x

Der Auslöser wird zu einem festen Zeitpunkt aktiviert, nachdem der Timer zurückgesetzt wurde.

WIRED AUSLÖSER: Punktzahl erreicht

Wird aktiviert, wenn die angegebene Punktzahl erreicht ist

WIRED Auslöser: Spiel endet

Der Auslöser wird aktiviert, wenn ein Spiel mit einem Timer-Möbel im Raum zu Ende ist.

WIRED Auslöser: Spiel beginnt

Der Auslöser wird aktiviert, wenn ein Spiel mit einem Timer-Möbel beginnt.

WIRED AUSLÖSER: Kollision

Wird aktiviert, wenn ein (mit dem Wired Verfolgen oder Fliehen) bewegtes Möbel mit einer Person zusammenstößt; der auslösende User ist die Person, mit der es zusammenstößt.

WIRED AUSLÖSER: Regelmäßig Lang

Längere Spiele! Der Auslöser wird jedes Mal aktiviert, wenn die angegebene Zeit um ist. Wie der Auslöser Regelmäßig, nur länger!
